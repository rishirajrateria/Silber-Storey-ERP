# DECISIONS.md — choices made where the spec was silent or the environment forced a change

- **Embeddings column**: `DocumentChunk.embedding` is `Float[]` (cosine similarity computed in the API) because pgvector could not be installed in the build environment. Docker Compose uses the `pgvector/pgvector:pg15` image; switching to a `vector(768)` column + `<=>` operator is a single migration + one query change in `services/rag.ts`.
- **Mock sign-in**: `POST /auth/dev-login {email}` (and the user picker on `/login`) exists only when `MOCK_MODE=true`, so the demo walkthrough works without Google credentials. Google OAuth is the real adapter.
- **PWA**: a hand-written `public/sw.js` (app shell + last GET responses) is registered in production instead of `next-pwa`, which is unmaintained for Next 14. Offline queue/IndexedDB uses `idb` as specified.
- **UI kit**: shadcn-style primitives are implemented locally in `components/ui.tsx` (glass styling, Tailwind) rather than generated by the shadcn CLI — same patterns, fewer dependencies.
- **Job queue**: BullMQ is used when `QUEUE_MODE=bullmq`; default dev mode uses in-process timers (`timer`), tests use `inline` (synchronous). Handlers are identical across modes.
- **PDF rendering**: in `MOCK_MODE` the branded HTML is stored under the `.pdf` key and served as HTML; the real adapter renders the same HTML with Playwright. Text is always stored first (spec 0.6).
- **Extra columns**: `MinutesOfMeeting.token` (public objection link), `Message.attachmentKey` and `Message.holdUntil` (quiet-hours hold), `createdAt` on a few tables. All spec field names are kept.
- **Message ×3**: email is skipped when the client has no email; SMS + WhatsApp always go to the phone.
- **Milestone % change**: on approval the delta is rebalanced from the last pending milestones so the schedule still sums to 100 %.
- **Invoice amounts** are GST-inclusive milestone amounts (quote total × pct); subtotal is derived by dividing out GST so the invoice total equals the milestone.
- **Admin view-as** is a read-only internal proxy (`x-view-as` header on `app.inject`), logged as `view_as`.
- **Admin lead detail** lives at `/admin/leads/[id]` (the spec lists no admin lead route; roadmap/lost-lead links need one).
- **Free/busy for other users** (rule 9.13) returns only busy blocks, never client details.
- **No-show worker**: online meetings past `endAt` with no accepted invite or no bot recording are marked `no_show`.
- **Report schedules** run from an hourly tick and respect `lastRunAt` + frequency.
- **Immutability** of Transcript/MoM is enforced by a Postgres trigger (`20261009170000_immutable_text`).
- **Migration ordering**: migration folders are timestamped; the trigger migration is dated after `init`.
- **Theme**: single committed dark glass theme (user request). Branding primary colour is applied as the accent only when bright enough to read on the dark surface (relative luminance ≥ 0.45); otherwise the default cyan stays.
- **Second client meeting**: requires a Junior to be assigned (Design Head + Junior are auto-attendees and get calendar entries); explicit per-person consent is not a separate step.
- **Travel time** in My Day is estimated from straight-line distance at 22 km/h plus 5 min in mock mode; the real Maps adapter can swap in Distance Matrix.
- **Invoice cancellation** is its own approval type (`invoice_cancellation`); only invoices without payments can be cancelled, otherwise a credit note is used.
- **Stage thresholds** (`Setting.stageThresholdDays`) drive the red roadmap steps; separate from the Delay rules that notify users.
- **PDF text blocks** (`Template.channel = pdf`: quote_intro, invoice_footer, receipt_footer) are Admin-editable; the PDF layouts themselves stay code.
